# Long Horizon Agent Maintenance

一个帮助 Agent 持续推进长期、多会话或多人接力项目的维护 Skill。它把规则、当前状态、发现和下一步写入项目文件，让新的 Agent 能从明确的停点继续工作。

适用于长期开发、重构、迁移、审计、研究、数据工作和形式化验证；一次会话即可完成的小修复通常不需要启用。

## 使用

将本目录放入 coding agent 的 Skill 目录，或直接让支持 Markdown 指令的 Agent 加载 [`SKILL.md`](./SKILL.md)。

Skill 不强制目录结构。先检查项目现状并尊重用户意愿，选择合适的控制面：

- `.project/` 本地控制面：适合探索期和短期接力；
- `.project/` 独立 Git 仓库：适合需要独立保留文档历史的项目；
- workspace 控制面：由 workspace 仓库追踪推进文档，代码仓库保持独立。

Agent 开始工作前会读取规则和当前状态，结束时留下验证结果并更新状态，并写出下一步的任务来驱动循环。文档可以放在 `.project/`、workspace 或项目的 `docs/` 中，但同一事实只能有一个来源。

继续工作时可以直接使用下面的 prompt，并把路径替换成项目实际位置：

```text
继续这个长期项目：先读取 <.project 或 workspace 文档路径> 中的规则、当前状态和相关 findings，核对代码与最近证据；选择状态里一个已授权且未阻塞的最小下一步，完成并验证后更新状态、追加本轮日志，记录未完成事项和下一步，不要静默扩大范围或把未验证内容写成已完成。
```

完整的规则、模板、迁移说明和首次启动 prompt 见 [`SKILL.md`](./SKILL.md)。
